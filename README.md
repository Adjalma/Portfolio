# Portfólio — Adjalma Aguiar

Portfólio profissional responsivo com apresentação de experiência, projetos e contatos.

## Tecnologias

React 18, React Router, Material UI e TypeScript.

## Desenvolvimento

```bash
npm install
npm start
```

## Build

```bash
npm run build
```

O deploy configurado usa GitHub Pages (`npm run deploy`). Configurações locais devem ficar em `.env`, que não deve ser versionado.
